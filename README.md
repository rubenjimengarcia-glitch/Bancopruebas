# Banco de Prueba

Web de guías y comparativas de herramientas a batería (bancodeprueba.com). Astro, estática.

- `npm install` y `npm run dev` para verla en local.
- Ajustes generales, ID de afiliado de Amazon y datos del aviso legal: `src/config.ts`.
- Plataformas de batería: `src/data/platforms.ts`.
- Plantilla de comparativa (no indexada): `src/pages/borradores/plantilla-comparativa.astro`.

En Vercel se detecta como proyecto Astro sin configuración adicional.
