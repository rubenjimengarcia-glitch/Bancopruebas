# Checklist del Verificador

Responde APROBADO solo si TODO se cumple. Si no, RECHAZADO con la lista numerada de fallos y la corrección exacta.

- [ ] Cada cifra de la página (par, peso, medidas, capacidades) aparece en el dossier con URL.
- [ ] Ninguna frase afirma pruebas propias, uso real ni experiencia con el producto.
- [ ] La página no usa "probado" ni "hemos probado" (no hay pruebas propias); no hay columna "Probado".
- [ ] No hay precios, estrellas, número de reseñas ni citas de reseñas de Amazon.
- [ ] Cada botón lleva un ASIN que figura en el dossier como verificado hoy, y el modelo coincide con el ASIN.
- [ ] El texto no promete "mejor precio", "oferta" ni disponibilidad.
- [ ] Hay contras reales en cada modelo y un "para quién no es".
- [ ] Aviso de afiliado presente; enlaces con `rel="sponsored nofollow"`.
- [ ] Enlaces internos funcionan y la guía figura en `index.astro`.
- [ ] No hay imágenes copiadas de Amazon ni imágenes generadas presentadas como reales.
- [ ] La página compila (`npm run build`) sin errores.
- [ ] Tono creíble: sin superlativos vacíos, sin adjetivos sin dato.
